# Кондитерская «Konditer» — Автоматизированная информационная система

Информационная система для автоматизации работы кондитерского магазина, управления заказами и взаимодействия с клиентами.

## Основные возможности

- **Авторизация и роли**: Разграничение прав доступа для Клиентов и Администраторов.
- **Каталог товаров**: Удобный просмотр ассортимента кондитерских изделий с изображениями и ценами.
- **Система корзины**: Добавление товаров, изменение количества и автоматический расчет итоговой стоимости.
- **Управление заказами**: Оформление покупок и сохранение истории заказов в базе данных.
- **Администрирование**: Управление базой данных пользователей и мониторинг активности.

## Технологический стек

- **Платформа**: .NET Framework / WPF (Windows Presentation Foundation)
- **Язык**: C#
- **База данных**: SQLite (локальный файл `konditer.db`)
- **Сторонние библиотеки**: System.Data.SQLite, Xamarin.Essentials

## Структура проекта

- `Model/` — логика доступа к данным и классы-модели (`User`, `Order`, `Product`).
- `Image/` — графические ресурсы и фотографии товаров.
- `*.xaml` — визуальные компоненты окон (Авторизация, Профиль, Корзина и др.).
- `*.xaml.cs` — логика обработки событий и бизнес-логика интерфейса.

## Быстрый старт

1. **Клонирование**:
   ```bash
   git clone <repository_url>
   ```
2. **Сборка**:
   - Откройте файл `Konditer.sln` в Visual Studio 2022 или новее.
   - Восстановите NuGet-пакеты.
   - Соберите проект (Build -> Build Solution).
3. **Запуск**:
   - Убедитесь, что файл базы данных `konditer.db` находится в директории с исполняемым файлом (`/bin/Debug`).
   - Запустите приложение (F5).
